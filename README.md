# mapMA

An interactive map of the AP Art History unit on modern art, where users can learn, memorize, and visualize the details of various artworks. 

A project for my personal experimentation in React, Vite, Framer Motion, and p5.js! 


### Build Instructions

To run the development server:

```bash
npm run dev
```

The application will start on `http://localhost:5173` (or another available port).


### Technical Stack

Completed as part of the course AET 330T: Exploring User Interaction.
